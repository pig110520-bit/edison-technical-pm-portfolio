01 / Context

From inherited routines to reliable tools.

原承辦人員調整職務後，我承接了核帳、入點和交易協查等既有業務。過程中發現大量時間花在查找日報表、人工比對與 Excel 名單整理，因此配合公司推動 AI 應用的方向，主動將可規則化的步驟做成小工具。

由我定義資料來源、欄位、重複判斷、輸入輸出與例外條件，使用生成式 AI 協助 Python 程式撰寫及除錯；開發後先以模擬資料測試，再與人工處理結果交叉比對，確認符合業務規則後才投入使用。

02 / Tools and workflow

Actual tools, actual workflows.

01 / RECONCILIATION

帳務核對與差異整理工具

將每月多類別交易明細依業務規則分組、判斷重複、排序及彙整，輸出核帳檔與排除清單。保留原始資料，另存結果供人工確認及後續作業。

Python · openpyxl · Windows Excel automation · GUI
02 / POINTS PROCESSING

入點名單產製工具

依已確認的核帳檔標記回查交易明細，以訂單及必要的替代條件配對會員識別碼與點數，產出匯入名單，降低人工複製時的配對錯位風險。

Python · Excel processing · Tkinter GUI
03 / INFORMATION LOOKUP

交易協查 Excel 批次比對工具

銀行、電子支付等外部窗口提出交易協查後，先將待查交易整理成 Excel；工具依交易日期及識別欄位，比對既有系統每天產出的超商收單交易明細，輸出對應門市代號、門市名稱等整理結果，再供人工確認與回覆。此工具不進行詐騙認定。

Batch lookup · Existing daily files · Excel export
